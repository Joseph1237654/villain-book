# 最初材料中的待检验命题

用户提供的两段长文是本书的思想起点。其作者、首发位置和引用链尚未给出。本文件只记录其中需要处理的问题，不将转贴内容视为用户原创或已核实文献。

## 一、可以保留的问题，不能直接接受的结论

| 材料中的说法 | 本书怎样处理 | 还需要什么 |
| --- | --- | --- |
| 越有魅力，越有一致性 | 作为研究假设：行动一致是否解释了某些人物的吸引力 | 同样坚定却没有魅力的角色，以及矛盾而有魅力的反例 |
| 一致性就是知行合一 | 分开使用。前者在本书指承诺与行动的关系，后者有王阳明思想中的具体语境 | 见 SRC-004；后续若深入哲学比较，再补专门研究 |
| 笃定能制造共识和凝聚力 | 追问笃定如何被表达，又在什么环境中得到响应 | 有证据的具体组织情境；不能只靠虚构角色推导人类普遍规律 |
| 魅力来源于远古群体的生存需要 | 暂不采用因果解释 | 可靠研究，尤其要区分演化假说与实证支持 |
| 可以把自己建立成个人宗教 | 当作一种强调自我承诺的修辞，同时检查它是否排斥纠错 | 公开承诺与信念封闭的区别 |
| 大众只是等待指引、并不在意善恶 | 不作为人群事实，也不用于贬低读者 | 若研究追随，需分析利益、处境、信息与选择 |
| 对过去绝不后悔 | 改为问题：承担责任、承认判断失误和反复自责分别是什么 | 能区分三者的具体选择 |
| 对现在绝不妥协 | 追问什么应守住，什么可以谈判和调整 | 原则、方法、资源约束与他人利益的区别 |
| 只要想做，就立即去做 | 保留行动意愿，把行动规模与可逆性写清 | 一次可承担代价的小试验 |
| 未来无所谓 | 不采纳为实践建议 | 计划可以修订，但后果仍需预估 |

## 二、审美距离这条线怎样进入书里

可以问：知道是虚构故事，是否使读者更容易欣赏危险人物？同一情节怎样让人被吸引，同时又反感？作品如何呈现代价，是否改变我们的判断？

暂不写成“审美与道德没有关系”。最初材料本身也承认二者存在影响。书中应允许读者说“写得好，但让我厌恶”，也允许说“让我着迷，但我反对他”。

“心理距离”若作为正式理论使用，需要另查理论原文和适用范围。当前试写主要依靠文本比较，不声称已经验证了这项心理机制。

## 三、暂不进入正文的材料

以下内容在来源清楚以前，只作为查证任务：

- 两则《奥赛罗》演出现场枪击观众或演员的故事。
- 关于陈强被观众袭击的具体细节，以及转贴中混用的作品名称。
- 归于席勒、朱光潜的说法和原句。
- 现实犯罪人物的引语、经历与其受欢迎程度之间的因果解释。
- 用希特勒演讲直接解释一般人格魅力的推论。

虚构人物足以承担当前试写任务。后续确有必要使用现实历史案例时，再单独核查，不以流传广泛代替可靠。

## 四、这本书暂用的工作定义

**行动一致性**：一个人在具体情境中，是否让自己的承诺、选择和承担代价的方式彼此相符。它不是人格优劣的总分，也不保证目标合理。

**自主**：能够辨认自己的理由，在现实约束中作出选择，并保留拒绝、求助和转向的可能。这是本书的工作用法，不试图替代完整的哲学定义。

**理性**：让判断接受事实与反驳，比较可选行动，承认不确定，并根据结果修订。

**负责**：说明自己作了什么选择，处理相应后果；在伤害他人或判断失误时，愿意纠正和补救。

这些定义服务当前写作。正式章节若需要更严格的概念，应说明扩展了哪一层。
